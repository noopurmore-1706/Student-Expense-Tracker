Student Expense Tracker 💰

📌 About the Project

The Student Expense Tracker is a simple Python-based mini project designed to help students manage and keep track of their daily expenses.

It allows students to record their spending, categorize expenses, calculate total expenditure, and maintain a record of their transactions. The project aims to encourage better money management and budgeting habits among students.

✨ Features

- Add daily expenses.
- Categorize expenses such as Food, Travel, Shopping, Education, etc.
- View all recorded expenses.
- Calculate total expenses.
- Track spending history.
- Simple and user-friendly menu-driven interface.

🛠️ Technologies Used

- Python
- File Handling
- Functions
- Lists and Dictionaries
- Object-Oriented Programming
- Exception Handling

▶️ How to Run the Project

1. Download or clone this repository.
2. Make sure Python is installed on your system.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file.

python main.py
